# LangChain Gemma Chatbot

A simple AI chatbot built using LangChain and Google's Gemma 4 model.

## Features

- Console-based chatbot
- Powered by Gemma 4
- Uses LangChain
- Secure API key with .env
- Beginner-friendly project

## Tech Stack

- Python
- LangChain
- Google Generative AI
- python-dotenv

## How to Run

1. Clone this repository.
2. Install the required packages.
3. Create a `.env` file and add your Google API key.
4. Run:

```bash
python GEMMA_CHATBOT.py
